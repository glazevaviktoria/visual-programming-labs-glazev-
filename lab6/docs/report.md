**Студент:** Глазева Виктория

## Описание базового приложения
Создано мобильное приложение «Приветствие». На экране есть поле для ввода имени, кнопка «Поздороваться» и два Label (для вывода результата и для фамилии). Реализована проверка: если поле пустое, выводится «Введите имя!», если заполнено — «Привет, [имя]!».

## Реализованные ачивки
**Ачивка 5: Расширение (Extension).** Установлено расширение Feather Icons. С его помощью добавлена иконка на кнопку приветствия. Использованы блоки расширения.

## Использованные AI-промпты
1. "Как в Kodular сделать проверку на пустое поле TextBox?" — для генерации блоков if/then.
2. "Как вывести всплывающее уведомление в Kodular?" — для реализации логики.

## Освоенные компоненты и блоки
- Компоненты: Label, TextBox, Button.
- Блоки: when Button.Click, if/then, is empty, not, join, set Label.Text.
