\# Sequence Diagram — Аренда автомобиля



```mermaid

sequenceDiagram

&#x20;   participant K as Клиент

&#x20;   participant P as Приложение

&#x20;   participant S as Система каршеринга

&#x20;   participant B as Платёжный шлюз

&#x20;   participant A as Автомобиль



&#x20;   K->>P: Открыть карту и найти авто

&#x20;   P->>S: Запрос списка свободных машин

&#x20;   S-->>P: Список с координатами

&#x20;   P-->>K: Показать карту



&#x20;   K->>P: Забронировать авто

&#x20;   P->>S: Создать бронь



&#x20;   alt Документы не загружены

&#x20;       S-->>P: Требуется загрузка документов

&#x20;       P-->>K: Запрос документов

&#x20;       K->>P: Загрузить права и паспорт

&#x20;       P->>S: Отправить документы на проверку

&#x20;   else Документы в порядке

&#x20;       S-->>P: Проверка пройдена

&#x20;   end



&#x20;   par Проверка состояния авто

&#x20;       S->>A: Запрос телеметрии

&#x20;       A-->>S: Уровень топлива, статус

&#x20;   and Заморозка депозита

&#x20;       S->>B: Заморозить депозит

&#x20;       B-->>S: Депозит заморожен

&#x20;   end



&#x20;   S->>A: Команда открыть двери

&#x20;   A-->>K: Двери открыты

&#x20;   K->>A: Начало поездки

&#x20;   A->>S: Данные о поездке



&#x20;   S->>B: Списать стоимость

&#x20;   B-->>S: Платёж выполнен

&#x20;   S->>B: Разблокировать депозит

&#x20;   S-->>K: Чек и оценка поездки

```
