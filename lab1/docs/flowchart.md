\# Flowchart — Проверка клиента перед арендой



```mermaid

flowchart TD

&#x20;   A(\[Начало]) --> B\[Авторизация клиента]

&#x20;   B --> C{Документы загружены?}

&#x20;   C -- Нет --> D\[Загрузить права и паспорт]

&#x20;   D --> E\[Проверка документов]

&#x20;   E --> C

&#x20;   C -- Да --> F{Права действительны?}

&#x20;   F -- Нет --> G\[Отказ в аренде]

&#x20;   G --> H(\[Конец])

&#x20;   F -- Да --> I{Достаточно средств<br/>для депозита?}

&#x20;   I -- Нет --> J\[Предложить сменить карту]

&#x20;   J --> I

&#x20;   I -- Да --> K\[Заморозить депозит]

&#x20;   K --> L\[Открыть автомобиль]

&#x20;   L --> M(\[Аренда подтверждена])

```
