- **Версия Node.js:** v24.22.0

## Выполненные потоки
В ходе работы были созданы и сохранены 12 потоков (файлы лежат в папке `flows/`):
1. **flow-01-inject-debug.json** — Базовая связка Inject -> Debug.
2. **flow-02-function.json** — Использование Function-ноды (работа с массивом и циклом).
3. **flow-03-switch.json** — Ветвление Switch (направление по двум путям).
4. **flow-04-change.json** — Изменение свойств сообщения (Change node).
5. **flow-05-template.json** — Генерация текста по шаблону (Mustache).
6. **flow-06-http-request.json** — Запрос к публичному API (факты о котах).
7. **flow-07-mqtt.json** — Публикация и подписка на MQTT-брокере HiveMQ.
8. **flow-08-endpoints.json** — Создание трех GET-эндпоинтов (включая валидацию и ошибки 400/404).
9. **flow-09-dashboard.json** — Визуализация данных (Gauge и Chart).
10. **flow-10-telegram.json** — Telegram-бот (команда /start и эхо-ответ).
11. **flow-11-files.json** — Чтение и запись файла JSON.
12. **flow-12-context.json** — Работа с flow context (счётчик).
