\## Краткое описание выполненного

В ходе работы была установлена и настроена платформа автоматизации n8n (через npm, так как Docker не был установлен). Были созданы 6 базовых workflow с использованием различных нод, а также настроены два workflow для работы с базой данных Redis.



\## Использованные AI-промпты

1\. "Как установить n8n на Windows без Docker?"

2\. "Как настроить работу с Redis в n8n, если нет оригинального сервера?"

\## Освоенные ноды

\- Manual Trigger — ручной запуск.

\- Schedule Trigger — запуск по расписанию.

\- Set (Edit Fields) — изменение полей.

\- Code — выполнение JavaScript-кода.

\- IF — ветвление.

\- HTTP Request — запросы к API.

\- Redis — запись, чтение и удаление ключей.



\## Выводы

В ходе работы я освоила n8n как low-code инструмент для автоматизации. Научилась устанавливать платформу без Docker, настраивать ноды и связывать их в рабочие процессы. Разобралась с тем, как работают HTTP-запросы, расписания, условия и контекст. Также я настроила работу с Redis. Возникли сложности с форматом данных при чтении из эмулятора redis-local (n8n возвращал null), но логика работы с базой была настроена.



Использование ИИ применялось для генерации кода функций, консультаций по настройке Redis и подготовки текстов документации. Итоговая сборка и отладка выполнены самостоятельно.
